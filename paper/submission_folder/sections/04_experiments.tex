\section{Experiments}
\label{sec:experiments}
\label{sec:setup}

Our experiments address four questions.
%
\textbf{(Q1)} Does transport improve held-out forecasting over matched predictors on real-robot and surgical video?
%
\textbf{(Q2)} Does the \ours{} head improve \emph{published} world models?
%
\textbf{(Q3)} Why does it work?
%
\textbf{(Q4)} Which components matter?
%
Model selection uses validation splits only, and every test split is scored once.

\paragraph{Datasets.}
\textbf{DROID} \citep{khazatsky2024droid} contains real Franka episodes, which we split by recording session.
%
We train on the primary exterior camera and test zero-shot transfer to the second; one step is 0.33\,s with a 35-D
Cartesian and gripper action block, and we forecast $K{=}10$ steps (3.3\,s).
%
\textbf{Open-H Hamlyn} \citep{openh2026embodiment} contains seven dVRK surgical training tasks with 80-D bimanual action
blocks and episode-disjoint splits per task.
%
\textbf{Language-Table} \citep{lynch2023interactive} shows an xArm pushing rigid blocks, taken from a pinned Open-X
subset \citep{oneill2024openx}.
%
For the plug-in study, we use PushT and Wall with the official \textbf{DINO-WM} code.
%
\Cref{tab:datasets} lists sizes, splits and licences.

\paragraph{Baselines.} All learned predictors share a frozen DINOv2-S/14 encoder ($16{\times}16$ patches, no pooling),
the same memory encoder and decoder (width 384, $L_e{=}L_d{=}4$, $\approx$22M parameters), optimiser, schedule, steps and
batch size, and differ only in the output head and rollout.
%
\textbf{Direct} replaces \cref{eq:output} with $\Z_0+\mathbf{W}_o\h_k$; it has the same cross-patch attention as
\ours{}, so it controls for spatial communication.
%
\textbf{AR} predicts a residual to the most recent grid and is rolled out recursively, with gradients through the
rollout.
%
\textbf{AR-TF} follows DINO-WM, as it is trained with teacher forcing to predict absolute features and rolled out at
test time.
%
\textbf{Persistence} copies $\Z_0$, and \textbf{Linear} extrapolates the last feature difference.
%
As published models, we use V-JEPA 2-AC and DINO-WM with and without the \ours{} head.

\paragraph{Metrics and statistics.} The primary metric is standardised feature MSE on held-out episodes, averaged over
horizons and at the final step.
%
We also report \emph{skill}, the fraction of persistence error a model removes, which is scale-free and therefore
compares models in different feature spaces.
%
Episodes are the statistical unit, and \cref{app:exp} gives all hyperparameters, data details and statistical
procedures.
