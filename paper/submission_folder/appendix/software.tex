\subsection{Software: the shiftwm package}\label{app:software}
The forecaster, the plug-in head and the evaluation helpers are also packaged as a small Python library,
\texttt{shiftwm} (MIT licence, depending only on PyTorch and NumPy), separate from the research code. It
exposes \texttt{ShiftWM}, the forecaster of \cref{sec:arch} with a loader for training checkpoints;
\texttt{ShiftHead}, the backbone-agnostic plug-in head of \cref{app:plugin}, $\hat\Z=(1-g)\mathbf{P}+g\mathbf{T}$ with
the gate closed at initialisation; \texttt{forecast}, which also returns the transport weights, gate and correction;
\texttt{transport\_field}, the expected source offset of every patch; and \texttt{skill}, $1-\mathrm{MSE}/\mathrm{MSE}_{\text{persist}}$.
\Cref{fig:sw-code} shows the API. \Cref{fig:sw-term} is a captured terminal session, trimmed only where marked
``\ldots'': the 16\,kB wheel is installed into a fresh virtual environment, the quickstart runs on CPU with random
features, the trained DROID (DINOv2-S) checkpoint forecasts one test window, and the test suite confirms that the
package reproduces the research implementation (maximum absolute difference $0$ on that checkpoint and below
$10^{-5}$ for random weights of every arm) and that \texttt{ShiftHead} starts at the backbone's prediction.

\par\medskip\noindent\begin{minipage}{\linewidth}
\begin{tcblisting}{vswindow=vsBg,listing only,listing options={style=vscode},title={\vsdots\hspace{2mm}usage.py}}
# pip install shiftwm-0.1.0-py3-none-any.whl       (requires torch, numpy)
import torch
from shiftwm import ShiftWM, ShiftHead, forecast, transport_field, skill

# 1. Load a trained forecaster (checkpoint {"model": state_dict, "config": dict}).
model = ShiftWM.from_checkpoint("best.pt")

# 2. Forecast K steps from H observed patch grids and the actions.
#    hist [B,H,N,C] features; past [B,H-1,A], future [B,K,A] actions.
pred, det = forecast(model, hist, past, future, return_details=True)
gate = det["gate"]               # [B,K,N,1] share of each patch that is transported
flow = transport_field(det)      # [B,K,N,2] expected source offset (dx, dy), patches
print(skill(pred, target, hist)) # 1 - MSE / MSE(persistence)

# 3. Wrap an existing patch-token predictor with the plug-in head.
head = ShiftHead(token_dim=384, grid=16, sources=2)  # gate closed: g = 0.018
wm = head.wrap(backbone)         # backbone(obs) -> P, or (P, hidden)
z_hat = wm(hist)                 # (1 - g) * P + g * T(observed tokens)
\end{tcblisting}
