# Nine-source teaser

Run `.venv/bin/python paper/scripts/render_teaser_benchmarks.py` from the repository root. This creates the selected5.5 × 3.25 in PDF/SVG/PNG and native editable draw.io artifact. Python is the canonical geometry source; `geometry.json` records its exact primitive geometry.

Inputs are public source PNGs and manifests under `benchmark_gallery`, `teaser_cinematic`, `teaser_gallery`, `spatial_qualitative`, `visual_story_references_v1`, and `paper/figures/split_assets`, plus the public DROID result ledgers/protocol receipts. Raw MP4s, NPZs and dataset folders are provenance references only, never renderer inputs. `paper/design/teaser_benchmarks/portable_reproduction.json` documents isolated regeneration.

Scope: DROID is the completed current spatial-decoder development comparison. IWS three tasks are ongoing-training input examples. PushT/Reacher/drone/tissue simulations belong to historical context-model studies. Open-H is a physical-phantom input audit only, not clinical patient data or a trained/evaluated model. The scalar 5.30% and all 141 outcome marks apply only to DROID.

See `../benchmark_gallery/ATTRIBUTION.md` and `../benchmark_gallery/benchmark_inventory.json` for all input selection/provenance. DROID and Open-H are credited CC BY 4.0; IWS must not inherit its model repository license as a dataset license. Generated camera assets are explicitly illustrative and have a separate imagegen provenance receipt. All nine source images remain unmodified and uncropped.

Native `.drawio` shapes, text, connectors, matrices and port marks remain editable; source photos and the camera are movable raster image objects. SVG retains editable text/vector geometry. SVG export-time metadata may differ on rerun while geometry remains identical.
