# Recorded-camera teaser — reproducible source

Run from the repository root:

```bash
python paper/scripts/render_teaser_camera_story.py
```

The script exports `paper/generated/editorial/teaser_camera_story.{pdf,svg,png,drawio}` and its caption, include and evidence ledger. Use `--drafts` to reproduce the three composition sketches under `paper/design/teaser_camera_story/`. Matplotlib, NumPy and Pillow are required; raw videos, cached features, model execution and GPUs are not. The portable renderer relies on public JSON experiment ledgers to recompute the complete outcome band. Native draw.io rendering is an additional check performed separately through diagrams.net; XML creation alone does not certify a native preview.

One geometry source creates the figure and native editable labels, camera parts, feature grids, arrows and marks. Only the eleven observed image panels are raster assets. SVG export metadata may contain a changing creation date. The native export uses absolute rounded-corner sizes from the same geometric radii; there are no dense activation curves disguised as graph edges.

## Scientific scope

The three DROID photographs are unchanged registered support frames0/5/10 from the median episode-gain case, first eligible window. The larger final observation is the same registered representative used by the earlier teaser. The compressed source interface denotes all three encoded observed support states plus the fixed last-observed source Z0. ShiftWM queries retain this interface; the gray autoregressive control rolls its own feature forecast into its next history while its original inferred context remains fixed. Each future query has its own available causal command prefix. The two 4×4 forecast grids are schematic horizon1/10 feature outputs, not measured tensors, physical patch tracks or generated RGB.

The eight secondary examples are disconnected from the DROID method graph: four historical simulations use distinct context models; three IWS examples are ongoing training inputs; Open-H is a physical stomach-phantom input audit, not patient surgery or an evaluated model application. Nine source settings therefore appear in eleven complete observed images. `asset_manifest.json` records exact bytes, decoded RGB hashes and provenance; the authoritative scope inventory is `paper/figure_sources/benchmark_gallery/benchmark_inventory.json`.

All141 DROID development episode marks remain visible (136 positive,5 negative). Uncertainty is reported in the paper's quantitative result figure. No new model inference or outcome selection occurs here.
