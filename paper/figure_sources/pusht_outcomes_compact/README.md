# Compact original PushT outcome strata

Run `python paper/scripts/render_pusht_outcomes_compact.py`. Runtime inputs are
only this directory's JSON/PNG/caption files. No raw simulator data, model,
cluster or private design directory is needed to render.

All20 PNGs are full unchanged224×224 observations extracted from original
matched development executions. Fourteen are displayed; all Shared-context
terminal outcomes and full records remain in data.json/source images. Original
intermediate trajectories are retained in the archived gallery and source NPZs.

Original source paths/hashes in data.json are archival provenance, not runtime
reads. In particular the manuscript section hash records extraction time, and
may differ after the new plate is integrated without any scientific change.

The compound native512-coordinate position criterion is distinct from the
individual block/pusher diagnostics. The persistent greenT is not scored.
Support-only case2031026 is not evidence for planner competence.

All numerical labels and vector outlines remain editable through renderer/SVG;
recorded RGB arrays are immutable raster evidence.
