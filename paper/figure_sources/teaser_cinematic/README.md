# Cinematic teaser source bundle

Regenerate from repository root with `.venv/bin/python paper/scripts/render_teaser_cinematic.py`. The renderer checks authoritative DROID ledger hashes, independently reconstructs all9786window scores, and preserves every episode mark. It creates three genuinely different draft compositions, then exports the selected5.5×3.0in candidate as PDF/SVG/PNG and native editable draw.io XML using the same primitive geometry. Labels are Liberation Sans8pt or larger.

`population.json` is the exact audited DROID development ledger, not an independent test or robot-control outcome. `asset_manifest.json` records fixed selection and RGB hashes. IWS thumbnails are three separate first sorted internal-training episodes/frame0; their training is ongoing and no outcome is shown. DROID attribution is preserved in `DROID_ATTRIBUTION.md`; the upstream IWS dataset does not have a specified dataset-card license, so its model repository license must not be assigned to these images.

The generated camera under `../visual_story_references_v1/` is an illustrative RGBA object, distinct from observed data. Its generation prompt and source-reference receipt are preserved. The reference image guided composition but is not embedded in the final figure.

`geometry.json` is a reproducible exported snapshot of all editable shapes, labels, ports and lines. The Python renderer is canonical. Manual draw.io changes must be migrated back to this geometry source before regeneration. Native-app/browser review, if performed, is recorded separately; deterministic Matplotlib exports are not presented as a diagrams.net export.

No frozen scientific source, result, test payload, model or canonical paper include is modified by this candidate renderer.
