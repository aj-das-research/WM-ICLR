\subsection{From the inference path to measured execution}
\label{sec:technical-qualitative}
Figure~\ref{fig:technical-contract} isolates the implementation difference.
Framewise calibration still uses a temporal, action-conditioned predictor;
its image residual is applied independently to each frame. ShiftWM instead
infers an observation context from support statistics, calibrates history and
goal with that shared context, and infers a dynamics context from corrected
transitions and executed actions. The second context modulates action
embeddings. Contexts change after observed action blocks but remain fixed
inside a CEM search; model weights remain fixed during deployment.

\begin{figure}[ht]
\centering
\includegraphics[width=\linewidth]{generated/qualitative/technical_contract.pdf}
\caption{\textbf{What changes in the computation.} Both methods use the same
frozen encoder, predictor architecture, history/action interface and CEM,
with separately trained predictor weights. Framewise applies a per-image
residual MLP; ShiftWM (ours) adds observation and dynamics contexts.
The goal is calibrated but never enters context inference. GRU inputs are
$[z_i,z_{i+1}-z_i,\widetilde a_i]$; $E_a(a)$ embeds executed past and candidate
future actions. This code-derived schematic describes operations and does
not establish component causality.}
\label{fig:technical-contract}
\end{figure}

Figures~\ref{fig:technical-pusht} and~\ref{fig:technical-reacher} examine the
first positive discordant task in each environment under the previously
declared lexicographic rule. We replay saved actions for \emph{all thirteen}
discordant tasks across three methods, including the nine Framewise-only
successes. The diagnostic requires exact agreement with every archived goal
and observed frame, as well as support/terminal errors and stopping behavior.
Intermediate physical states are reconstructed by this verified replay;
they were not policy inputs or newly selected control actions.

Panel~B separates the two conditions actually required for success. Its
green regions represent the original task tolerances, and trajectories end
at their real stopping times. Panel~C is a distinct, conditional prediction
test: both trained checkpoints receive the same three observed frames, two
past action blocks, and next executed five-action block. Error is measured
against the same canonical next-observation feature from the frozen encoder.
Canonical images are diagnostic targets only; they do not enter context
inference. Partial terminal blocks have no full-block forecast measurement.
After the common start, the two behavior policies visit different states,
so predictions are compared within each observed transition.
Panel~C uses logarithmic MSE axes. Percentage labels show relative change
against Framewise: green $\downarrow$ is lower error and red $\uparrow$ is
higher error. Missing terminal measurements indicate an incomplete five-action
block, never zero error. These diagnostics do not recover CEM candidate rankings
or identify which component caused a successful action sequence.
