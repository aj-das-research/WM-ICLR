\subsection{From the inference path to measured execution}
\label{sec:technical-qualitative}
Figure~\ref{fig:technical-contract} joins the historical inference paths with
matched execution diagnostics. Framewise uses a temporal, action-conditioned
predictor with an image residual applied independently to each frame. ShiftWM
infers an observation context from support statistics and a dynamics context
from corrected transitions and executed actions. The former calibrates history
and goal; the latter modulates action embeddings. Goals and future actions
never enter context inference. The methods share the frozen encoder and
predictor architecture but have separately trained predictor weights. Deployment
weights stay fixed, while contexts update after observed action blocks and
remain fixed inside each CEM search. This historical context model is distinct
from the spatial model in Figure~\ref{fig:editorial-spatial-method}.

Panels B and C examine the first positive discordant case in each environment
under the declared lexicographic rule. We replay saved actions for \emph{all
thirteen} discordant tasks across three methods, including nine Framewise-only
successes. Replay matches every archived goal and observed frame, support and
terminal errors, and stopping behavior. Reconstructed physical states are
measurement targets, never policy inputs or newly selected actions.

Each task panel separates both conditions required for success. Green regions
show the original tolerances, and traces stop at the actual native call. The
lower plots test both checkpoints on identical three-frame histories, two past
action blocks and the next executed five-action block, against the same
canonical next-observation feature. Canonical images are evaluator-only targets.
After common support, the policies visit different states, so comparisons are
paired within each realized transition. Partial terminal blocks have no
full-block measurement; they are omitted, never plotted as zero.
