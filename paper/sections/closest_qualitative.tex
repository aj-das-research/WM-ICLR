\paragraph{A fixed selection rule retains difficult cases.}
The DROID gallery extends the original three-case replay by adding the same
three seeds of the closest no-$\tanh$ component. It preserves the original
largest, median and smallest episode-gain cases and their first eligible
windows. The main-paper maps use the identical observations and withheld
target for all three methods. Their errors are averaged after squaring each
seed's prediction error in training-standardized coordinates.

For IWS, we conduct a separate, explicitly posthoc diagnostic on the completed
reserved comparison. Within each task, we rank all ten trajectories by the
no-$\tanh$ ablation's endpoint MSE reduction against fixed autoregression,
averaging the original handles within each trajectory and then three seeds.
We select largest, middle-ranked (fifth of ten) and smallest gains, breaking ties by trajectory
identifier, and show each trajectory's smallest registered start index. The
rule is fixed before replay or image inspection. It neither changes the
selected checkpoints nor feeds future training or model selection. A favorable
trajectory average can contain a regressing displayed window; both scores are
shown. Figure~\ref{fig:closest-iws-gallery} preserves these disagreements.

\paragraph{Case-specific findings.}
In the middle-ranked Rope window, no-$\tanh$ has MSE 0.2103, versus 0.2278 for
autoregression and 0.2341 for bounded ShiftWM. All three selected Rope windows
show the same ordering between no-$\tanh$, autoregression and the bounded
model. The selected PushT trajectory with the smallest positive average gain,
however, contains a displayed window that regresses by 11.78\%; the smallest
Box window regresses by 17.84\%. DROID's median episode gives another reversal:
its fixed window favors no-$\tanh$ (0.1698) over autoregression (0.1722), while
bounded ShiftWM is slightly worse (0.1727). These examples explain the range
of behavior without turning the selected gallery into an estimate of its
frequency. The complete trajectory counts and paired comparisons supply that
broader context.

\paragraph{A temporal view separates early accuracy from endpoint accuracy.}
Figure~\ref{fig:temporal-qualitative-outcomes} follows the same middle-ranked
IWS windows, with recorded targets, spatial error differences and every measured
forecast step aligned. These are offsets within the full 60-command forecast;
offsets 14, 29, 44 and 59 correspond to the stored $H=15,30,45,60$ states.
In the Rope window, no-$\tanh$ starts with 33.69\% higher error than
autoregression at the first forecast offset, but ends with 7.67\% lower error.
The PushT and Box middle windows end at 8.34\% and 7.57\% lower error.
The plot uses absolute MSE differences rather than percentage curves, so a small
early baseline error does not visually dominate the later comparison.
These paths are nonmonotonic: a favorable endpoint need not mean a uniformly
better forecast. The smallest-gain PushT and Box windows in
Figure~\ref{fig:closest-iws-gallery} provide the converse, ending with worse
error after favorable earlier offsets. DROID has the same temporal caveat:
in its median case, bounded ShiftWM's gain against autoregression changes from
9.76\% at $h=5$ to $-0.31$\% at $h=10$.

\paragraph{What changes inside the decoder?}
Figure~\ref{fig:closest-decoder-internals} follows one actual row of the
effective mixing matrix at a fixed destination patch $q$ (row 2, column 2).
Gating gives $W_h=I-D_h+D_hT_h$; the correction adds new feature values to
$W_hZ_0$. All four maps read the same observed source $Z_0$, despite changing
future targets. In the PushT no-$\tanh$ example, the weight on the source at
$q$ decreases from 0.69 at offset 14 to 0.45 at offset 59; Box changes from
0.32 to 0.23, and Rope from 0.36 to 0.23. The remaining weight reads other
observed feature locations. These are measured mixtures, not uniform copying.
The common query index is fixed before inspecting outcomes.

The right-hand traces in Figure~\ref{fig:closest-decoder-internals} distinguish
two whole-grid quantities: the mean gate and the RMS correction over
$16\!\times\!384$ coordinates. We compute each
seed's weights, gates and RMS before averaging. Thus the curves do not describe
only the marked query, and the correction trace is not a mean of patchwise
RMS values. Both the primary bounded model and its no-$\tanh$ ablation remain
visible. These source weights are not object attention, pixel saliency or
physical correspondence; differences in their trajectories and correction
magnitudes describe the computation without isolating the cause of an accuracy
gain. The controlled component comparisons supply the performance evidence.

\paragraph{Replay and image provenance.}
All shown methods use identical features, native command prefixes, frozen
training statistics and targets. IWS uses the unchanged reviewed row-wise CPU
GRU backend with eight intra-operation threads and one inter-operation thread.
All seeds and displayed offsets are checked against the finalized window
ledgers; detailed and ordinary inference must agree. Forecasts are reconstructed
from their recorded $W_hZ_0+\Delta_h$ terms. The derived source pack records
checkpoint, case, frame and source hashes. Recorded images supply scene context;
none is a decoded forecast. DROID images retain CC BY 4.0 attribution to the
dataset contributors. IWS excerpts are attributed to the RLA-WM/IWS dataset;
its dataset license is unspecified. Original RGB, features and commands remain
local and are not included in the new public numerical source pack.
