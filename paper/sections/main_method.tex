\section{Observation-anchored spatial prediction}
\label{sec:editorial-method}
ShiftWM predicts a future feature grid from fixed observed evidence and a
causal action prefix. Figure~\ref{fig:editorial-spatial-method} links the fixed
observed memory, horizon-specific conditioning and patchwise decoder, with
withheld target features kept in a separate scoring path.

\subsection{Observed support and causal action conditioning}
Let $Z_0\in\R^{16\times384}$ be the last observed DINOv2-small grid,
standardized with training-only channel statistics. A shared spatial encoder
maps each observed grid into 96-dimensional patch embeddings. In the DROID instantiation, a single
support context summarizes only observed transitions. A separate
unidirectional GRU encodes the chronological action prefix, and the reused
temporal predictor produces a horizon-specific patch state $H_h$.
The observed support stays fixed as the query horizon increases; imagined
images never become new support evidence. Feature standardization is inverted
when predictions are returned in the encoder's coordinates.
The single-image IWS adapter repeats the initial grid into three architectural
slots and omits transition context and FiLM; it does not invent observed history.

\subsection{A fixed anchor, gated mixing and bounded correction}
Let $E_0$ denote the last observed spatial encoding \emph{before} context
modulation. Queries from $H_h$ and keys from $E_0$ give
\begin{equation}
 T_h=\operatorname{softmax}_{\rm row}\!\left(
 \frac{Q(H_h)K(E_0)^\top}{\sqrt{96}}+4I\right),\qquad
 g_h=\sigma(G(H_h)).
 \label{eq:editorial-mixing}
\end{equation}
The identity bias favors preserving patch identity initially. The affine
gate head $G$ acts on each patch and broadcasts over channels; its bias
initializes at $-3$.
The prediction is
\begin{equation}
 \widehat Z_h=(1-g_h)\odot Z_0+
 g_h\odot(T_hZ_0)+\tanh R(H_h).
 \label{eq:editorial-forecast}
\end{equation}
The residual head $R$ uses normalization and an affine projection. Both the
mixture source $Z_0$ and key representation $E_0$ come from the last observation
at every horizon. Mixing semantic feature patches need not correspond to
physical pixel motion.

Writing $D_h=\operatorname{diag}(g_h)$ gives row-convex weights
$W_h=I-D_h+D_hT_h$. Hence each output channel lies between
$\min_k Z_{0,k,c}-1$ and $\max_k Z_{0,k,c}+1$ in standardized coordinates.
This bounds output range, not forecast accuracy or stability. We test
bounding's incremental benefit by removal: the no-$\tanh$ ablation replaces
$\tanh R(H_h)$ with $R(H_h)$, preserving observed-memory mixing and all information
inputs. The range bound applies only to the bounded model.

\subsection{Training and component controls}
All DROID component arms use the same frozen features, training data and selection
recipe. We compare autoregression and persistence with the proposed model,
then remove mixing, bounding, actions or the separate support-context path.
Removing both mixing and bounding gives an additive anchor; adding bounding
back yields a bounded-anchor control. These are controlled alternatives,
not separately proposed algorithms. The mixing package includes its gate and
identity bias and, in DROID, adds about 1.84\% active parameters; the comparison therefore
tests that package rather than a capacity-identical isolated operation.
Exact objectives, dimensions, temporal indexing and stable checkpoint names
are in Appendix~\ref{app:spatial-development}.

\subsection{Relation to existing world models}
We reuse pinned LeWM prediction components \citep{maes2026lewm,maes2026stable};
compactness is an upstream property. ContextWM and ICWM condition predictions
on scene or interaction histories \citep{wu2023contextwm,wang2026icwm}.
MoVie and AdaJEPA study visual or online adaptation
\citep{yang2023movie,wang2026adajepa}; our evaluated weights remain fixed at
inference. ReDRAW and RLA-WM use residual modeling
\citep{lanier2025redraw,zhang2026rlawm}, so a residual head alone is not our
contribution. We investigate the \emph{fixed observed source} of spatial mixing
and its controlled alternatives. DA-LeWM motivates separating prediction
quality from planning-cost alignment \citep{wang2026dalewm}. Our comparisons
are matched design controls, not independent reproductions establishing
state-of-the-art superiority.
