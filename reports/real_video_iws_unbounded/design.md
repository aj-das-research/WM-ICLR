# IWS unbounded-innovation component ablation

This is a new exploratory study designed after observing the original internal-development results. It is a component ablation of the existing model, not a new proposed algorithm or a reserved-validation experiment.

The sole mathematical intervention is to replace `innovation = tanh(residual)` with `innovation = residual` in the fixed-source spatial mixer. Observed source features, query/key projections, identity bias, sigmoid gate, chronological native-command GRU, temporal predictor, normalization and output coordinate system remain identical. The original `innovation_bound=1` configuration field is retained for recipe/state compatibility but does not clip the ablation's correction. All learned parameters and buffers, including active parameter flags, must initialize exactly like bounded v1 under the same seed.

The complete grid contains nine runs: PushT, Bimanual Box and Bimanual Rope × seeds 0, 1 and 2. It uses the same frozen internal-training/development split, caches and statistics, one initial observation, 60 native command rows and all59 future-offset loss, 30 full epochs, effective batch64 (microbatch64), AdamW1e-4/weight decay0.01, cosine floor1e-6, clipping1, BF16 training, and FP32 equal-trajectory endpoint H60 selection with earliest strict-minimum tie handling. No v1 model/data/training/registration file is edited.
