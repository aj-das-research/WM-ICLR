## Findings resolved before registration

1. **The original cross-resolution evaluator used approximately equal targets.** Pooling newly extracted 4×4 features to 2×2 passes an extraction tolerance but does not establish exact equality with the original cached targets. The original normalization floor of 1e-5 can amplify tiny raw discrepancies. The evaluator now loads the exact original validation targets and persistence anchors, matches episode/session/window identities, and scores pooled forecasts against those targets. A regression fixture with a 1e-5 target discrepancy and 1e-5 standard deviation correctly reports MSE 1 rather than 0. Both manifest hashes and the coordinate contract accompany results.
2. **The finalizer previously trusted stored summaries.** A separate validator now derives the complete eligible validation window population from both manifests; rejects missing, duplicate, or mismatched windows/episodes; checks all ten finite nonnegative errors for four metrics; reconstructs window-to-episode and equal-episode aggregates; and binds model/configuration/checkpoint/normalization/source identities. The finalizer invokes it after the authoritative full-30-epoch checkpoint validator and before export or aggregation. Twenty-nine independent tests cover malformed ledgers, altered arithmetic and identities, unequal episode window counts, and paired comparison population/seed requirements.
3. **Registration previously allowed duplicated run entries.** It now requires the complete five-mode × three-seed Cartesian product, unique names and configuration paths, and matching configuration identities.
4. **One extraction test originally invoked the real lazy Transformers loader.** An isolated deterministic module fixture now provides the intended synthetic encoder. The fixture also proves that an absent test payload is never opened. Causal fixtures now use nonzero output and FiLM heads, avoiding trivial persistence-only passes.

## Scientific and engineering contracts checked

**Causality.** Predictions consume three observed feature grids, two observed command blocks, and a unidirectional prefix of recorded future commands. Query images contribute only to targets/loss. Context is fixed from observed support; there is no query-dependent context refresh. A separate learned-like-weight probe randomized every trainable parameter, tested all five modes, and found zero query-image gradients and zero later-command gradients for earlier forecasts. Changing later commands and shortening the requested horizon left earlier predictions exactly unchanged. Action-free predictions were exactly invariant to changing every command. Results are in `spatial_independent_causality_probes.json`. Invariance comparisons use the same inference context: gradient-enabled versus no-gradient attention kernels differed by at most 2.38e-7 in FP32, which is an execution-path roundoff effect, not an action leak.

**Coordinates and bound.** Channel-major ordering, 4×4-to-2×2 pooling, and shared per-channel train-only statistics are explicit and tested. Shared normalization places every transported patch in a common coordinate system. A row-stochastic transport, a sigmoid identity/transport gate, and a tanh innovation bounded by 1 imply each output channel component is bounded by the largest absolute anchor patch component in that channel plus 1. Nonzero-weight probes satisfied this tighter per-channel bound for transport, context-off, and action-free modes. This says nothing about predictive accuracy, physical safety, or a Lipschitz constant.

**Data isolation.** Extraction filters original train/validation metadata before opening video payloads. Spatial manifests reject any test row. Dataset selection and training-statistics fitting respect splits before loading/aggregating payloads; session overlap is rejected. The original and fresh test outcomes are not valid new model-selection evidence and are not used by this campaign.

**Training and completion.** The isolated reuse of the existing trainer retains atomic packages, optimizer/scheduler/RNG continuation, complete epoch journals, first-minimum checkpoint selection, and full-30 completion checks. Selection is window-weighted FP32 MSE across all ten steps; equal-episode validation is auxiliary, while the final report is equal-episode then equal-seed. A synthetic full lifecycle test completed 30 epochs both continuously and after an epoch-boundary interruption, obtaining identical histories and model tensors. Relocated isolated-process inference exports passed exact CPU prediction parity. Incomplete runs cannot reach evaluation or a completed receipt.

**Resource accounting.** The reviewed benchmark and campaign cap projected training at 80 total GPU-hours, computed as three seeds times the sum of the five per-arm 30-epoch estimates, with a separate 20-hour per-model ceiling. This corresponds to about 26.7 ideal wall-hours on three GPUs, not 80 wall-hours. Extraction, checkpoint I/O, contention, and scheduling overhead are explicitly excluded from the estimate.

**Scheduler control flow.** Four separately mocked cases verified requeue on an unfinished allocation, rejection without a Slurm allocation, rejection after the restart limit, and evaluation only after completion. No actual scheduler command was issued by these probes. Real cluster requeue behavior and throughput remain operational checks for the allocated jobs. Results are in `spatial_independent_controlflow_probes.json`.

## Fairness and interpretation limits

- All five arms share the representation, observation/action information budget except intentional ablations, training recipe, ten-step selection, and evaluation population. The candidate is a new spatial architecture family, not the unchanged original factorized ShiftWM model.
- Capacity is approximately matched: transport has 1,026,305 active parameters versus 1,007,776 for either additive arm (+1.84%); context-off has 878,497 and action-free 988,001. All include 1,026,305 total instantiated parameters, with inactive parameters frozen. These counts and the near-persistence versus exact-persistence initialization difference must remain disclosed.
- The five arms identify a combined architecture effect. They do not isolate transport from bounded innovation, establish novelty, or compare with every external state of the art. Semantic latent transport is not a demonstrated physical image warp.
- All registered positive and negative results must be reported. Session-and-seed bootstrap comparisons are exploratory original-validation evidence; the multiple comparisons are not multiplicity adjusted.
- Export finalization deliberately refuses an existing export directory. An interruption during export therefore requires inspecting/staging the incomplete directory before a retry. A partial directory is not a completed release; publication must require the authoritative successful finalization and parity records. This is an operational recovery limitation, not grounds to skip validation.
