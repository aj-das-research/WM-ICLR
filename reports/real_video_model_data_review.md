# Independent real-video model/data review

**46 contract tests passed** in 14.92 s after fixes made by the source owner. Test coverage and exact reviewed source hashes are recorded in `reports/evidence/real_video_model_data_review.json`; output is in `reports/evidence/real_video_model_data_tests_short_episode.log`. The reviewer edited only tests and evidence, not the production model/data/features modules.

The tests verify identical common initialization across four modes, initial persistence, recursive horizon 10, causal action indexing, and no future-target leakage through values or gradients. Changing future target images changes the loss but leaves predictions and support-derived contexts identical. Later future actions cannot alter earlier predictions. All three action-conditioned modes develop nonzero action sensitivity after two optimizer updates, while the action-free control remains exactly invariant after training. The two-update delay follows the intentionally zero-initialized output head and upstream AdaLN gates.

Windows retain the exact five-native-call by seven-action-component grouping, and never cross physical episodes. Training statistics use only training data from the primary camera, with sample standard deviation; changing even the readability of held-out payloads has no effect on fitted statistics. Session overlap, incomplete/empty manifests, duplicate episodes, missing/unknown splits, malformed frame indices, wrong action dimensions, nonfinite inputs, and corrupted payloads are rejected.

The review identified and the owner fixed incomplete-input acceptance, orphan-cache adoption under a new encoder identity, unbound/stale extraction receipts, silent cache re-extraction after corruption, invalid singleton/fractional frame indices, and nonfinite normalization statistics. Resume now requires a matching extraction identity and verified payload/receipt pair. The tests also verify frozen/eval encoder use, the declared camera policy, and exact offline checkpoint reconstruction from pinned vendored LeWM code without network access.

These are correctness tests using synthetic tensors and a dummy frozen encoder, not model-performance results. The source RLDS decoder's recording-session fallback rules and successful/negative-trajectory flag preservation remain the responsibility of its separate extraction audit. Actual pretrained DINO inference in GPU precision is still an integration check of the allocated feature-cache job. No accuracy, generalization, control-success, or training-throughput claim follows from this review.

A source-data edge case was found before the feature job started: some episodes yield only one grouped observation and zero action blocks. The owner amended the minimum length accordingly. Two added regressions verify that these real episodes remain in the cache and training feature statistics, contribute zero action samples and zero prediction windows, and never produce fabricated transitions.
